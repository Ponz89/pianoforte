# Pianoforte per imparare

Tastiera di pianoforte per tablet: tocco multiplo, nomi delle note, Do centrale evidenziato, spostamento di ottava.
Funziona anche offline una volta aperta (web app installabile).

**Apri l'app:** https://ponz89.github.io/pianoforte/

Sul tablet: apri il link con Chrome → menu ⋮ → "Installa app" / "Aggiungi a schermata Home".
